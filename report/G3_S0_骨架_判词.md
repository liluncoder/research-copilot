## 环境坑记录（★跨项目有效，已入用户级记忆）

1. **pip 全局配置坏**：`%APPDATA%\pip\pip.ini` 的 `index-url` 缺 `/simple` 后缀 ⇒ 所有默认源安装报
   "(from versions: none)"。已修复为 `https://pypi.tuna.tsinghua.edu.cn/simple`。
   另：本机 pip 直连清华源仍不稳，**阿里源 `https://mirrors.aliyun.com/pypi/simple/` 实测可用**。
2. **PowerShell 通道会弄乱中文**：命令行参数里的中文到达 PowerShell 时已被错误解码
   （git commit -m 中文变乱码即此因）。⇒ **铁律：中文内容一律用 Write 工具落文件，
   PowerShell 命令保持 ASCII**。
3. **沙箱 safe-delete fail-closed**：临时文件删不掉（trash 失败），只能靠 .gitignore 屏蔽
   （已加 `_*` 与 `*.log` 规则）。桌面/工作区残留 `_` 开头文件需用户手动清理。
