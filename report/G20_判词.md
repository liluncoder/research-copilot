## 一、为什么不是 HF Spaces

原计划是 HF Spaces Docker（免费 cpu-basic）。2026-10-18 实测创建仓库返回 **402**：

> Static Spaces are free for everyone, but hosting Gradio and Docker Spaces on free
> cpu-basic requires a PRO subscription.

账号 `luniy` 的 `isPro=false`、`canPay=false`，所以 HF 路线只能作为备选（需要 PRO）。
改走 **ModelScope 创空间**：免费 `platform/2v-cpu-8g-mem`、国内直连、创空间对外端口固定
**7860**，正好是镜像里 Next 的端口。同一镜像仍保留 HF 的 `README.md` 元数据，有 PRO 时可原样推。

## 六、已知限制（如实写）

1. **免费实例 2 vCPU / 8 GB**：BGE-M3 冷启动约 18 秒（已做启动预热）；
   冷启动完成前的第一次问答会明显慢。索引构建在镜像里完成，不占运行期。
2. **无持久盘**：容器重启后，运行期新上传的 PDF 会丢；预置 9 篇不受影响。
   演示前已把语料与索引打进镜像，评审看到的不是"空库"。
3. **网关会拦默认 Python UA**：`ms.show` 对 `Python-urllib/3.11` 返回 403；
   `verify_deploy.py` 已带浏览器 UA。这不是应用鉴权，浏览器访问正常。
4. **跨文献串答**：问"训练用了多少块 GPU"时，回答除 8×P100 外还引了 LLS 的 4×A40
   与 e-prop 致谢里的 Quadro P6000。三条都是真文献、有出处、零编造，但问题本身没限定
   是哪篇论文 —— 属于演示语料多篇混排时的正常现象，也暴露"跨文献对比"尚未做限定。
5. **OCR 未在创空间实测**：镜像补了 OpenCV 运行库（`libxcb`/`libGL` 等），
   但演示语料全是文本层 PDF；扫描件上传路径只在本地 J3 判据里验过。
6. **HF 备选未上线**：HF Docker Space 需要 PRO；`deploy_hf.py` 与镜像仍保留，
   有 PRO 后可原样推。
7. 构建期 `get_sentence_embedding_dimension` 有 FutureWarning（sentence-transformers 6.x
   改名），不影响加载与检索；后续可改 `get_embedding_dimension`。

## 七、复现命令

```powershell
# 1. 生成 staging（9 篇文献 + 索引 + 前后端源码，约 28MB）
python tools\deploy_hf.py

# 2. 推 ModelScope 创空间（token 从环境变量/.ms_token 读，不落盘）
$env:MODELSCOPE_TOKEN='ms-...'
python tools\deploy_modelscope.py --repo lixinci/research-copilot

# 3. 触发构建 / 看日志
modelscope --token $env:MODELSCOPE_TOKEN studio deploy lixinci/research-copilot
modelscope --token $env:MODELSCOPE_TOKEN studio logs lixinci/research-copilot --type build

# 4. 公网验收
python tools\verify_deploy.py https://lixinci-research-copilot.ms.show
```
