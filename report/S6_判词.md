## 四、两处"结构性防幻觉"（技术文档的主打设计）

| | J7 | J8 |
|---|---|---|
| 模型能看到的 | 只有统计量 | 只有候选文献 id + 标题 |
| 模型不能做的 | 编造数据点细节 | 编造参考文献条目 |
| 系统兜底 | 判据逐个核对图注数字 | 非法标记**直接删除**并记 `invalid_refs`；条目由元数据渲染 |

**共同点：不靠提示词求模型别编，而是不给它编的信息通道。**
提示词是软约束（模型可以无视），数据隔离是硬约束（没有信息可编）。

## 五、已知限制（如实写）

1. **对抗主题下仍会引用不相关的库内文献**：问「量子退火」，它会引用 9 篇 SNN 论文（虽然都是真文献、
   零编造）。已加提示词"A 与主题不相关就不要引用"，但模型仍偏保守地挂引用。
   改进方向：先做**相关性闸门**（检索分数低于阈值就不进候选清单），但目前 hash 向量档的分数不可比，
   换 BGE-M3 后再做更可靠。
2. **年份是猜的**：库里没有发表年字段，`_guess_year` 从首页文本里抓 1990~2026 的年份取最大值，
   个别论文会显示错（TESS/LLS 显示"年份未知"）。属展示瑕疵，不影响引用可溯源性。
3. 图注只支持折线/柱状/散点与"单指标 + 单分组"，多指标对比未做。
4. 学术翻译只做 zh→en，且未做术语表约束（同一术语在不同段落可能译法不一致）。
