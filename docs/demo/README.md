# 演示素材录制说明（李论专用）

> **这目录放什么**：每个阶段出口录的 30-60 秒屏录小片 + 关键截图。
> **为什么**：最终交付物是 **5-8 分钟 1080p MP4 演示视频**（D2，`路线/07 §二` 有分镜）。
> 这些小片是那支视频的**原料** —— 阶段出口当天录，S7 只做拼接，不从零录。
> 这是风险 **R5**（视频拖延到最后一晚）的唯一解药。

---

## 一、你只需要会三个动作

| 动作 | 按键 | 存成什么 |
|---|---|---|
| **截图** | `Win + Shift + S` → 框选 → 自动进剪贴板 | PNG，直接粘给我 |
| **录屏** | `Win + Alt + R` 开始 / 再按一次停止 | MP4，自动存在 `C:\Users\23810\Videos\Captures\` |
| **交给我** | 把文件拖进这个目录，或直接把图/视频贴进对话 | 我负责归位、命名、转格式 |

**GIF 转换、剪辑、拼接、加字幕、加旁白——全是我的活，你不用学。**

### 录屏前一次性设置（30 秒，只做一次）

按 `Win + G` 打开 Xbox Game Bar → 齿轮（设置）→ **捕获**：

- 视频质量：**1080p**
- 帧速率：**30 fps**
- 音频：开启（勾上"录制麦克风"，后期配音也方便）

### 录之前 10 秒的准备清单

1. 浏览器窗口最大化，按 `Ctrl + 0` 把页面缩放归到 100%
2. 关掉无关标签页（画面干净 = 评审印象分）
3. ★**确认屏幕上没有 `.env`、没有 key、没有聊天窗口** —— 录进去就是密钥泄露
4. 录音时不用背稿，一边操作一边小声说"这是上传、这是解析出来的结果"就够 ——
   顺便就是在练 S7 的串讲词
