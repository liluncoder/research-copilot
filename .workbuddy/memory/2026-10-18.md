### 4. 引用图谱"一闪一闪"：三个原因，逐个修
1. **边也参与 hover 聚焦** —— `emphasis.focus: "adjacency"` 对 node 和 edge 都生效，
   鼠标从两球之间划过落在连线上也会整图虚化。→ 给每个 link 加 `emphasis: { disabled: true }`
2. **线宽变化** —— `emphasis.lineStyle.width: 2` 让 hover 时 1.2→2 再变回，整片网抖一下。→ 删掉，改为只放大节点
3. **每次点击整图重排** —— setOption 重建 series 时 force 布局重新抖开。→ 加 `posRef` 缓存上一帧坐标并回填
另加：`tooltip: { show: false }` 给边（formatter 返回空串会留一个空框）、
`blur` 阈值调轻（与 data 里的 opacity 叠加会过淡）、`animationDurationUpdate: 280` 缓动过渡。

### 5. 加载动效
- 图谱画布：数据 260KB + echarts 初始化约 1~2 秒，加三点跳动占位「正在构建引文网络…」
- 全站：`.animate-fade-up` 加到 SiteShell 的 main，切页时轻微上浮淡入；首页卡片按 45ms 错峰入场
- 新增 CSS：`.dots` 跳动、`.skeleton` 呼吸
